# 设计规范

## 设计基准

以 [架构说明](ARCHITECTURE.md) 中固定的 Astro Cactus 提交为设计基准，保留作者的紧凑页眉与首页定制。保持窄幅、等宽、少量强调色和紧凑列表，不新增卡片墙、宣传式大标题或装饰动画。文章和个人介绍保留中文，导航、标题、搜索和代码控件使用英文；日期按 UTC 日历日显示为 `YYYY-MM-DD`，Giscus 保留中文。

实现入口为 `Base.astro`、`global.css` 和 `ec.config.mjs`。所有颜色仍以全局 token 为准；Typography 插件在 CSS 中注册，不新增第二套主题配置。

## 字体与布局

- 全站使用上游等宽栈：`ui-monospace`、`SFMono-Regular`、`Menlo`、`Monaco`、`Consolas`、`Liberation Mono`、`Courier New`，并提供 `Noto Sans Mono CJK SC` 与系统等宽回退。无远程字体。
- 基础字号 `14px`，行高 `20px`；正文采用 Typography 的 `prose-sm`，字号 `14px`、行高 `24px`。标题使用上游 `.title`，基础为 `24px`、字重 `600`。
- 页面最大宽度 `48rem`，水平内边距为 `1rem`，`sm` 起为 `2rem`；顶部内边距 `4rem`，页眉底部间距 `3rem`。
- 首页直接显示中文简介，与文章列表间距为 `3rem`；列表标题为链接至归档的 `More...`。不显示欢迎标题与社交链接，首页不生成 H1。列表使用日期、标题两列，移动端堆叠，条目间距 `1rem`。不展示旧摘要式列表及分隔线。
- 归档使用年份分组和 Tags 侧栏，`sm` 起采用 `3fr 1fr` 两列；移动端按文档流排列。
- 页眉仅显示文字站名，站名与导航在桌面位于同一行。`Home / Blog` 在桌面使用竖线分隔，移动端改为可展开菜单。搜索、主题及移动菜单按钮位于右侧。
- 页脚按当前定制仅显示作者和年份，保留上游间距与响应式对齐，不再重复导航或站点装饰。

搜索弹窗使用上游 `--pf-*` 样式变量；独立搜索页保留 `--pagefind-ui-*`，两者均映射同一组 token。`html[data-theme]` 是唯一配色状态。

## 文章与交互

正文使用上游 Typography 样式及 Cactus 定制。标题标记在 `sm` 起显示，装饰标记不进入可访问名称。引用不加左边线，行内代码使用点状边框，表头和水平线使用虚线。图片限制在容器内，长代码与表格独立滚动。

文章头部使用标题、日期、阅读时间、可选更新日期和标签。目录可折叠，H2～H4 嵌套；`lg` 起位于右侧并固定在距离顶部 `3rem` 处，窄屏回到正文之前。返回顶部按钮只在文章头部离开视口后显示，隐藏时不可聚焦。

搜索图标打开上游 Pagefind 弹窗。支持键盘操作、Escape 关闭和焦点恢复，保留独立搜索页。菜单同步 `aria-expanded`，支持 Escape 关闭和焦点返回。

主题按钮同步 `aria-checked`，不显示旧“自动”按钮。默认仍跟随系统，手动选择跨页面持久化。Giscus 和 Expressive Code 随主题同步。

代码字号 `0.875rem`，行高 `1.7142857rem`，水平内边距 `1rem`，圆角 `4px`，取消框架阴影；行号、文件名、高亮与复制由 Expressive Code 管理。

favicon 使用 RealFaviconGenerator 的 `public/favicon.svg`，页眉不显示图标。下载文件放在 `public/` 根目录，全站统一声明，缓存版本为 `20261022`。

## 可访问性与验收

保留跳到正文链接、语义导航、按钮名称和焦点描边。首页按当前定制不生成 H1，其他页面保留唯一 H1。焦点描边为 `2px` 强调色，偏移 `5px`。减少动态效果的系统设置优先于主题动画和平滑滚动。

在 `375px`、`768px`、`1440px` 检查首页、归档、中文长文、标签与搜索，覆盖浅色、深色和键盘。整页不得产生意外横向滚动；代码与表格可局部滚动。图标、目录、搜索、评论和代码均须可操作。

运行方式及生产预览要求见 [贡献指南](CONTRIBUTING.md)。截图和成功声明以实际检查结果为准。
